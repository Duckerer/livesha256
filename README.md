# livesha256
Гибридный (CPU+GPU) инструмент на Rust и Vulkan для хеширования в реальном времени, брутфорса и проверки файлов. Скорость до 3.5+ GH/s.

## Особенности
- **Гибридный режим (CPU + GPU)**: Одновременная нагрузка на все потоки процессора (инструкции SHA-NI) и видеокарту (Vulkan Compute). Разделение диапазонов перебора для максимальной скорости.
- **Midstate Optimization**: Первые блоки сообщения и первые 11 раундов последнего блока предвычисляются на CPU. Видеокарта делает только оставшиеся 53 раунда.
- **Unrolled Shaders**: Полностью раскрученный шейдер без динамической индексации, что исключает обращение к медленной памяти GPU.
- **Real-time Hashing**: Мгновенный вывод хеша SHA-256 (и других) по мере ввода текста.
- **File Integrity**: Проверка файлов по контрольным суммам.
- **Поиск коллизий**: Возможность искать префиксы (включая сложные PoW-таргеты с ведущими нулями).

## Бенчмарки
*Тестирование проводилось на Intel Core i5-13400F + NVIDIA GeForce RTX 4060.*

| Режим | Скорость | Время на 10 символов (1.1 трлн) |
| :--- | :--- | :--- |
| Только CPU (16 потоков) | ~200 млн/с | ~1.5 часа |
| Только GPU (Vulkan) | ~3 млрд/с | ~6 минут |
| **Гибрид (CPU + GPU)** | **~3.56 млрд/с** | **~5 минут** |

## Установка и запуск

Для сборки потребуется установленный [Rust](https://rustup.rs/) и драйверы с поддержкой Vulkan.

```bash
# Клонируем репозиторий
git clone https://github.com/duckerer/livesha256.git
cd livesha256

# Сборка в релизном режиме (для максимальной производительности)
cargo build --release

# Запуск
cargo run --release
